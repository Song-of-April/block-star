# 离线方块消除游戏

这是一个面向 Android 手机的离线益智游戏，玩法接近“俄罗斯方块拼图 + 行列消除”。

目标是尽可能还原参考游戏的界面与操作体验，同时去掉登录、广告、联网、充值等内容。应用完成后应能直接安装到 vivo 手机上，无需网络即可游玩。

---

## 1. 项目目标

### 必须实现

- Android 原生应用。
- Kotlin + Jetpack Compose。
- 固定竖屏。
- 完全离线。
- 无登录、无广告、无联网权限。
- 10×10 棋盘。
- 底部每轮显示 3 个待放置方块。
- 手指拖动方块到棋盘中放置。
- 填满一整行或一整列后消除。
- 支持一次消除多行、多列，以及行列同时消除。
- 显示当前分数。
- 保存历史最高分。
- 保存当前未结束的棋局。
- 显示金币。
- 实现刷新、删除、增加三个道具。
- 死局时允许使用道具；放弃使用则结束游戏。
- 重新开始、暂停和继续游戏。
- 适配常见 vivo 手机屏幕。

### 后期实现

- 方块放置动画。
- 行列消除动画。
- 两条及以上消除时显示“好”“赞”等短暂提示。
- 星光粒子背景。
- 按钮发光和按压动画。
- 轻微振动反馈。
- 更精细的宝石方块素材。

### 不实现

- 登录。
- 广告。
- 排行榜。
- 账号同步。
- 充值。
- 网络请求。
- 背景音乐。
- 复杂设置页面。

## 2. 已确认的游戏规则

### 2.1 棋盘

- 棋盘固定为 10 列 × 10 行。
- 左上角坐标为 `(0, 0)`。
- 每个格子有“空”或“已占用”两种状态。
- 已占用格子记录颜色，仅用于显示。
- 颜色不影响任何消除规则。
- 棋盘上没有特殊障碍方块。

### 2.2 待放置方块

- 底部最多显示 3 个方块。
- 每轮生成 3 个方块。
- 玩家可以按任意顺序放置。
- 一个方块成功放置后，该槽位变空。
- 3 个方块全部放完后，生成下一组 3 个方块。
- 方块不能旋转。
- 方块不能翻转。
- 方块只能整体拖动。
- 方块不能重叠，也不能超出棋盘。

### 2.3 拖动操作

- 按住底部方块后开始拖动。
- 拖动时方块显示在手指上方，避免被手指遮挡。
- 当方块移动到棋盘上方时，显示落点预览。
- 合法位置使用明亮或半透明预览。
- 非法位置使用红色预览，或不显示预览。
- 松手时：
  - 合法：正式放入棋盘。
  - 非法：方块回到底部原位置。
- 拖动过程中不改变棋盘数据。
- 只有松手成功后才结算分数和消除。

### 2.4 消除规则

每次成功放置方块后，按以下顺序执行：

1. 把方块写入棋盘。
2. 找出所有已经填满的行。
3. 找出所有已经填满的列。
4. 将本次找到的所有完整行和完整列同时消除。
5. 同一个格子即使同时属于完整行和完整列，也只清空一次。
6. 消除后不发生重力下落。
7. 剩余方块保持原位。

### 2.5 分数规则

设本次放置的方块包含 `x` 个格子。

- 没有触发行列消除：本次增加 `x` 分。
- 触发至少一条完整行或完整列：本次增加 `x + 15` 分。
- 同时消除多行、多列时，仍暂定为 `x + 15` 分，不按条数重复增加 15 分。

所有计分规则集中写在 `GameConfig.kt` 中，后续可以只改一个常量。

建议定义：

```kotlin
const val CLEAR_BONUS = 15
```

本次得分：

```text
placedCellCount + (本次是否消除 ? CLEAR_BONUS : 0)
```

### 2.6 当前分数与最高分

- 当前分数显示在屏幕顶部中央。
- 历史最高分显示在当前分数下方。
- 每次得分后立即更新当前分数。
- 若当前分数超过最高分，立即更新最高分。
- 最高分必须持久化。
- 退出应用后再次进入，最高分不能丢失。
- 重新开始仅清空当前分数，不清空最高分。

### 2.7 鼓励提示

- 只消除 1 条线：只播放普通消除动画，不显示文字。
- 一次消除 2 条及以上：
  - 短暂显示“好！”“赞！”“太棒了！”中的一个。
  - 提示显示约 500～800 毫秒。
  - 不阻塞玩家继续操作。
- 鼓励文字只是视觉效果，不额外加分。

## 3. 道具规则

所有道具均为“点击后立即购买并使用”，不设置背包库存。

价格统一集中在 `GameConfig.kt` 中，方便以后调整。

### 3.1 删除道具

图标：橙色锤子。

暂定价格：50 金币。

流程：

1. 点击锤子按钮。
2. 若金币不足，显示简短提示。
3. 若金币足够，进入删除选择模式。
4. 棋盘上可删除的格子出现高亮。
5. 玩家点击一个已占用格子。
6. 扣除 50 金币。
7. 删除该单独格子。
8. 退出删除模式。
9. 删除后重新检查行列。
10. 若因此形成消除条件，正常执行消除；默认不增加“放置方块格子数”分数，只获得清除效果。
11. 玩家可点击取消，不扣金币。

注意：参考视频中的原游戏价格显示为 150，但本项目根据需求改为 50。

### 3.2 刷新道具

图标：蓝色循环箭头。

价格：150 金币。

作用：

- 刷新底部所有尚未放置的方块。
- 已经放到棋盘上的方块不受影响。
- 已经空掉的槽位仍保持空，或者仅刷新当前剩余槽位。
- 新方块应更容易放置。

“更容易”的实现方式：

1. 先列出当前棋盘上所有至少存在一个合法位置的形状。
2. 优先从简单形状池中选择：
   - 单格。
   - 横向 2 格。
   - 纵向 2 格。
   - 横向 3 格。
   - 纵向 3 格。
   - 小 L 形。
3. 若简单形状池中没有合法形状，再从全部可放置形状中选择。
4. 禁止刷新出当前棋盘完全无法放置的形状。
5. 扣除 150 金币后才替换。
6. 玩家确认前不扣金币。

### 3.3 增加道具

图标：粉色加号。

建议价格：150 金币，与参考视频一致。

作用：

1. 点击粉色加号。
2. 展示可以增加的简单方块列表。
3. 玩家选择一个形状。
4. 若存在空槽位，则把该形状放入一个空槽位。
5. 若没有空槽位，则允许替换玩家选择的一个尚未放置方块。
6. 扣除金币。
7. 玩家取消则不扣金币。

第一版可只允许增加以下形状：

- 单格。
- 横向 2 格。
- 纵向 2 格。
- 横向 3 格。
- 纵向 3 格。
- 2×2 方块。
- 小 L 形。

### 3.4 死局处理

“死局”定义：

- 当前底部所有尚未放置的方块，在棋盘上都不存在合法位置。

检测时机：

- 每次成功放置后。
- 每次生成新一组方块后。
- 使用道具后。
- 从存档恢复后。

死局时：

1. 棋盘变暗。
2. 显示死局弹窗。
3. 弹窗显示当前分数和最高分。
4. 提供：
   - 使用删除道具。
   - 使用刷新道具。
   - 使用增加道具。
   - 结束本局。
5. 只要道具使用后至少存在一个合法放置位置，就关闭弹窗并继续。
6. 点击结束本局后进入结算界面。
7. 不使用广告复活。

## 4. 金币策略

原游戏金币获取规则未完全确认，因此本项目采用简单、透明、适合离线游玩的规则。

### 初始值

- 首次安装赠送 200 金币。

### 建议获取规则

- 每消除 1 条完整行或完整列，获得 5 金币。
- 一次消除 2 条及以上，额外获得 5 金币。
- 每局结束时，根据分数奖励：
  - 100～299 分：10 金币。
  - 300～599 分：20 金币。
  - 600 分及以上：30 金币。

### 原则

- 不看广告。
- 不充值。
- 不联网。
- 金币不可为负数。
- 金币变动立即保存。
- 所有数值放入 `GameConfig.kt`，以后可随时修改。

第一阶段开发时，可以只实现固定初始金币和扣费；金币奖励放到道具阶段再实现。

- 纵向 2 格。
- 横向 3 格。
- 纵向 3 格。

- 纵向 4 格。
- 横向 5 格。

- 4 格 L。

- 5 格 T。

- 3×3 空心框。

## 6. 界面还原要求

### 6.1 整体布局

从上到下：

1. 状态栏安全区域。
2. 左上角暂停按钮。
3. 顶部中央当前分数。
4. 当前分数下方显示“最高分数：xxx”。
5. 右上角金币图标和金币数量。
6. 三个圆形道具按钮。
7. 10×10 棋盘。
8. 底部三个待放置方块槽位。
9. 底部安全区域。

### 6.2 配色

- 背景顶部为明亮青蓝色。
- 背景底部为深海军蓝。
- 背景有少量星星和闪光点。
- 棋盘内部为深蓝绿色。
- 棋盘边框为亮青色发光效果。
- 网格线为低亮度青色。
- 当前分数为橙黄色立体字。
- 最高分文字为白色。
- 方块使用红、黄、绿、蓝、紫五种颜色。

### 6.3 方块视觉

第一版：

- 使用 Compose 绘制圆角矩形。
- 中间使用主色。
- 上边和左边更亮。
- 下边和右边更暗。
- 添加轻微内阴影和高光。

第二版：

- 使用自制九宫格 PNG 素材。
- 每种颜色一张方块图片。
- 使用 `Image` 平铺到格子中。
- 不能直接复制原游戏素材，应重新绘制近似风格资源。

### 6.4 适配

- 固定竖屏。
- 使用 `WindowInsets.safeDrawing`。
- 棋盘宽度取屏幕宽度的约 90%。
- 棋盘必须保持正方形。
- 单格大小由棋盘实际宽度除以 10 得到。
- 不使用固定像素。
- 适配 720p、1080p、1440p 手机。
- 适配水滴屏、挖孔屏和底部手势条。
- vivo 手机上字体、按钮和拖动区域应保持清晰。

## 7. 数据保存

推荐使用 DataStore。

### 保存内容

- 历史最高分。
- 当前分数。
- 金币。
- 棋盘 10×10 状态。
- 底部 3 个方块。
- 每个方块的颜色。
- 当前是否存在未结束棋局。
- 是否首次安装。
- 振动开关。
- 最近一次保存时间。

### 保存时机

- 每次成功放置后。
- 每次消除后。
- 每次使用道具后。
- 金币变化后。
- 应用进入后台时。
- 暂停时。
- 结束本局时。

### 恢复规则

- 启动应用时若存在未结束棋局，直接恢复。
- 若没有存档，开始新游戏。
- 存档格式异常时，安全地新建游戏，不崩溃。

## 9. 分阶段开发路线

### 阶段 0：创建空工程

目标：

- Android Studio 能运行空白 Compose 页面。
- 固定竖屏。
- 包名确定。
- 禁止网络权限。
- 设置最低 Android 版本。
- Git 初始化。

验收：

- vivo 真机可安装。
- 无崩溃。
- 旋转手机时仍保持竖屏。

### 阶段 1：纯逻辑游戏引擎

先不做漂亮界面，也不做拖动。

实现：

- 10×10 棋盘。
- 方块数据结构。
- 合法放置判断。
- 放置。
- 行列检测。
- 同时消除。
- 分数计算。
- 死局检测。
- 单元测试。

验收：

- 能通过测试验证行消除、列消除、交叉消除和多线消除。
- 同一交叉格不会重复处理。
- 分数符合规则。

### 阶段 2：基础可玩界面

实现：

- 顶部分数。
- 最高分。
- 金币。
- 简单按钮。
- 棋盘网格。
- 底部 3 个方块。
- 先用“点击方块 + 点击棋盘”的临时方式放置。

验收：

- 完整玩一局。
- 三个方块放完后自动生成下一组。
- 发生死局时能结束。
- 当前分数和最高分正确。

### 阶段 3：拖动放置

实现：

- 按住底部方块拖动。
- 手指上方显示放大方块。
- 棋盘落点计算。
- 合法落点预览。
- 非法松手回弹。
- 防止重复提交。

验收：

- 方块可准确放到边缘和角落。
- 快速拖动不会错位。
- 松手时不会放到相邻错误格。
- vivo 真机操作顺畅。

### 阶段 4：存档

实现：

- DataStore。
- 保存最高分。
- 保存当前分数、棋盘和底部方块。
- 保存金币。
- 恢复未结束棋局。

验收：

- 强制关闭应用后再进入，棋盘恢复。
- 最高分不会因重新开始而消失。
- 数据损坏不会导致崩溃。

### 阶段 5：删除道具

实现：

- 删除选择模式。
- 点击一个已占用格删除。
- 价格 50。
- 金币不足提示。
- 死局弹窗中可使用。

验收：

- 取消不扣钱。
- 删除成功只扣一次。
- 空格不可删除。
- 删除后重新检测死局。

### 阶段 6：刷新道具

实现：

- 刷新剩余方块。

验收：

- 不会刷新出全部无法放置的形状。

### 阶段 7：增加道具

实现：

## 10. 核心验收用例

### 放置

- 单格放在四个角。
- 横向 5 格贴左、贴右。
- 纵向 5 格贴顶、贴底。
- 与已有格子重叠时拒绝。
- 超出边界时拒绝。

### 消除

- 填满一行。
- 填满一列。
- 一次填满两行。
- 一次填满两列。
- 同时填满一行和一列。
- 同时填满多行和多列。
- 消除后其他方块不下落。

### 分数

- 放 1 格且不消除：+1。
- 放 5 格且不消除：+5。
- 放 3 格并触发消除：+18。
- 放 9 格并触发多线消除：+24。
- 最高分实时更新。

### 道具

- 49 金币不能使用删除。
- 50 金币可使用删除且变为 0。
- 149 金币不能刷新。
- 150 金币可刷新且变为 0。
- 取消道具不扣金币。
- 死局时使用道具后可继续。

### 保存

- 退出后恢复当前局。
- 清除应用数据后恢复为初始状态。
- 重新开始不清空最高分。
- 卸载后数据允许清除。
